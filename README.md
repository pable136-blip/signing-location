# 행사 근무자 QR 출석

행사장 부스에 두던 **종이 근무자 서명부를 QR 출석으로** 바꾼다.
부스 태블릿이 QR 을 띄우고, 근무자는 휴대폰 기본 카메라로 찍어 출근·퇴근을 누른다.
기록은 구글 시트에 쌓인다(별도 서버·비용 없음).

## 「QR 사진으로 다른 곳에서 출석」 차단

| 수법 | 막는 장치 | 판정 위치 |
|---|---|---|
| QR 을 사진·캡처해 단톡방에 공유 | QR 이 **30초마다 바뀌고 약 1~1.5분 뒤 만료**. 토큰은 부스키로 만든 HMAC 이라 위조 불가 | 서버 |
| 스캔한 링크(주소)를 복사해 전달 | 링크에 같은 토큰이 들어 있어 똑같이 만료. 출석 화면은 열리자마자 주소창에서 토큰을 지움 | 서버 |
| 1분 안에 사진을 받아 멀리서 즉시 찍기 | 출석 순간 휴대폰 **GPS 가 행사장 반경 밖이면 거부**, GPS 오차 100m 초과·2분 넘은 위치값도 거부 | 서버 |
| 현장 동료가 내 이름으로 대신 찍기 | **근무자 1명 = 휴대폰 1대 고정**. 한 폰으로 두 사람 출석 불가, 처음 쓴 폰이 아니면 거부 | 서버 |
| 행사 전날·끝난 뒤 출석 | 행사 시작~종료 일시 밖이면 거부 | 서버 |
| 명단에 없는 사람 | 「사전명단만허용 = Y」 면 명단의 이름+연락처 뒤 4자리만 허용 | 서버 |

거부된 시도는 모두 **「거부기록」 시트**에 사유·행사장까지 거리·기기와 함께 남으므로,
반복해서 원거리 시도를 한 사람을 사후에 확인할 수 있다.

> 한계: 안드로이드 「가짜 GPS」 앱으로 위치를 조작하는 것은 웹 브라우저에서 완전히 감지할 수 없다.
> 다만 그 경우에도 **1분 안에 새 QR 사진을 받아야** 하므로 공모자가 현장에 있어야 하고,
> 기기 고정 때문에 그 공모자 폰으로 대신 찍을 수도 없다. 더 강하게 하려면 운영 시
> 부스 담당자가 「출석기록」 시트를 띄워 두고 출석자 얼굴과 대조하면 된다.

## 구성

```
booth.html          부스 태블릿용 — 행사ID·부스키 입력 후 30초마다 바뀌는 QR 전체화면
checkin.html        근무자 휴대폰용 — QR 스캔 시 열림, 이름·연락처 뒤 4자리 + GPS 로 출근/퇴근
config.js           Apps Script 웹 앱 주소(API_URL)
apps-script/Code.gs 서버(구글 시트에 붙이는 Apps Script)
vendor/qrcode.js    QR 생성 라이브러리(MIT, kazuhikoarase/qrcode-generator 1.4.4)
```

## 설치 (처음 한 번, 약 10분)

1. **구글 시트 만들기** — 새 스프레드시트 → 확장 프로그램 → Apps Script →
   `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장 → 함수 `setup` 선택 후 실행(권한 허용).
   「행사·근무자·출석기록·거부기록」 시트가 생긴다.
2. **웹 앱 배포** — Apps Script 에서 배포 → 새 배포 → 유형 「웹 앱」,
   실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포 → 웹 앱 URL 복사.
3. **config.js** 의 `API_URL` 에 그 URL 을 넣고 이 저장소에 커밋.
4. **GitHub Pages 켜기** — 저장소 Settings → Pages → 브랜치 선택 → 저장.
   `https://<계정>.github.io/signing-location/booth.html` 로 열린다(https 필수 — GPS·암호화 API 조건).

> Code.gs 를 고친 뒤에는 배포 → 배포 관리 → 수정 → 버전 「새 버전」 으로 다시 배포해야 반영된다.

## 행사마다

1. **「행사」 시트**에 한 줄 추가: 행사명, 위도·경도, 허용반경(m, 권장 150~300),
   시작일시·종료일시(예 `2026-10-10 08:00`), 사전명단만허용(Y/N).
   시트 메뉴 **출석관리 → 빈 행사ID·부스키 채우기** 로 행사ID·부스키를 자동 생성.
   - 위도·경도는 부스 자리에서 `booth.html` 의 「이 자리 좌표 보기」 로 확인하거나, 구글 지도에서 우클릭해 복사.
2. **「근무자」 시트**에 명단 입력(행사ID, 이름, 연락처 뒤 4자리). 기기ID 칸은 비워 둔다 — 첫 출석 때 자동 등록.
3. 부스 태블릿에서 `booth.html` 을 열어 행사ID·부스키 입력 → 「QR 띄우기」.
   화면 꺼짐 방지는 자동 요청되지만, 태블릿 화면 자동 꺼짐도 꺼 두는 것을 권장.

**부스키는 근무자에게 알려 주지 말 것** — 부스키가 있으면 어디서든 QR 을 만들 수 있다.
유출이 의심되면 시트의 부스키 칸을 지우고 메뉴로 다시 채운 뒤 부스 화면에 새 키를 넣으면 된다.

## 운영 중 자주 있는 일

- **「QR이 만료되었습니다」** — 스캔 후 오래 걸린 경우. 부스 QR 을 다시 찍으면 된다.
- **휴대폰을 바꿨다 / 브라우저 데이터를 지웠다** — 「처음 출석한 휴대폰이 아닙니다」 가 뜬다.
  담당자가 「근무자」 시트에서 그 사람의 기기ID·기기등록일시 칸을 지우면 다음 출석 기기로 다시 고정된다.
- **카카오톡 등 앱 안에서 열림** — 기본 카메라 앱으로 찍으면 크롬/사파리로 열린다.
  앱 안 브라우저는 위치 권한이 막혀 있을 수 있다.
- **위치 권한을 거부했다** — 브라우저 설정 → 사이트 설정 → 위치에서 허용 후 QR 재스캔.

## 설정값 (Code.gs 맨 위 `CONFIG`)

| 항목 | 기본 | 뜻 |
|---|---|---|
| `SLOT_SECONDS` | 30 | QR 교체 주기(초) — 부스 화면이 서버에서 받아 씀 |
| `SLOTS_PAST` | 2 | 지난 QR 몇 개까지 인정할지(스캔 지연 허용) |
| `MAX_ACCURACY_M` | 100 | GPS 오차 허용 한도(m) |
| `DEFAULT_RADIUS_M` | 200 | 행사 시트에 반경이 비었을 때 |
